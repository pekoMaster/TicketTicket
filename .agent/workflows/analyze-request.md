# 分析需求與程式碼定位工作流

當使用者送出新的需求時，AI 代理必須依序進行以下判斷與操作：

1. **確認需求內容**
   - 解析使用者的原始需求，列出預計修改或新增的功能點。

2. **依據需求尋找程式碼**
   - 先至 `.agent/features/` 目錄查詢是否已有該功能的說明文件。
   - 根據文件或透過搜尋工具（如 `grep_search`, `find_by_name`），找出實際對應的實作程式碼檔案。

3. **確認當前程式狀態**
   - 讀取找出的程式碼檔案。
   - 記錄並向使用者確認這些程式碼當前的運作邏輯與最新狀態，以確保後續修改的準確性。

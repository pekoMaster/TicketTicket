# 修改後檢查與版號更新工作流

當完成任何功能的程式碼修改並自我測試通過後，請執行以下流程：

1. **確認全語言支持 (i18n Check)**
   - 檢查本次修改中是否有新增或變更任何對話框、標籤或文字內容。
   - 確認所有支援的地區與語言檔（例如 `zh-TW`, `en` 等 JSON 檔或對應設定）都已經完整補上翻譯。

2. **更改版本號 (Version Update)**
   - 呼叫 `/version-update` 工作流（或參照其指示）來升級專案的版本號。
   - 確保 `package.json` 等重要檔案的版號有同步更新。

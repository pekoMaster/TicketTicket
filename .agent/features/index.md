# 票票網功能索引總覽 (TicketTicket Features Index)

這是一份票票網的核心功能索引指南，列出了系統中各個模組的主要邏輯路徑與說明文件。在進行特定模組的功能開發與修復前，請**務必詳閱對應的功能說明檔**，以掌握相關前端路由、元件、Context 以及 Supabase 後端資料庫表的關聯。

## 核心功能列表

1. [認證與註冊系統 (Authentication)](auth.md)
   - `auth.md` - 包含登入、Email/Phone 驗證、Onboarding。
2. [首頁與活動列表 (Homepage & Listings)](home-listing.md)
   - `home-listing.md` - 包含首頁展示、卡片排序篩選邏輯。
3. [會員中心 (Profile)](profile.md)
   - `profile.md` - 個人資料編輯與過往紀錄。
4. [聊天與私訊 (Chat & Messages)](chat.md)
   - `chat.md` - 即時訊息溝通系統。
5. [討論區版塊 (Forum)](forum.md)
   - `forum.md` - 社群發文互動區。
6. [通知系統 (Notifications)](notifications.md)
   - `notifications.md` - 系統推播與通知中心。
7. [後台管理系統 (Admin)](admin.md)
   - `admin.md` - 管理員功能、審核與檢舉。
8. [多語系支援 (i18n)](i18n.md)
   - `i18n.md` - 語系切換與翻譯檔架構。

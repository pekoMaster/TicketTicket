# i18n (多國語系支持)

## 功能說明
負責票票網介面文字的國際化（Internationalization），支援中文（繁體、簡體）、英文、日文等多種語言切換。

## 主要相關檔案
### 前端路徑
- **設定與工具**:
  - `src/i18n/` - next-intl 或自訂的語言配置檔
  - `messages/` (根目錄下) - 放置各語系翻譯 JSON 檔（如 `en.json`, `zh-TW.json`）
- **Context**:
  - `src/contexts/LanguageContext.tsx` - 負責管理與切換目前的語系設定
- **middleware**:
  - `src/middleware.ts` - 可能用於偵測使用者語系自動導向（若有使用 route-based i18n）

# 多語系支援 (i18n - Internationalization)

## 功能說明
使用 `next-intl` 實現多語系支援。目前支援 4 種語言，翻譯檔為 JSON 格式。

## 支援語系
| 語系 | 代碼 | 旗幟 | 翻譯檔 |
|------|------|------|--------|
| 繁體中文 | `zh-TW` | 🇹🇼 | `messages/zh-TW.json` |
| 簡體中文 | `zh-CN` | 🇨🇳 | `messages/zh-CN.json` |
| 日文 | `ja` | 🇯🇵 | `messages/ja.json` |
| 英文 | `en` | 🇺🇸 | `messages/en.json` |

## 相關檔案

### 設定
- `src/i18n/config.ts` — 語系設定（locales 列表、預設語系、localeNames、localeFlags）
- `src/i18n/request.ts` — next-intl 的 request 設定

### 翻譯檔
- `messages/zh-TW.json` — 繁體中文（主要開發語系）
- `messages/zh-CN.json` — 簡體中文
- `messages/ja.json` — 日文
- `messages/en.json` — 英文

### Context
- `src/contexts/LanguageContext.tsx`
  - `locale` — 當前語系
  - `setLocale()` — 切換語系（存 cookie）

### 元件
- `src/components/ui/LanguageSwitcher.tsx` — 語系切換器（button / menu-item 兩種變體）
- `src/components/layout/LanguageModal.tsx` — 語系選擇彈窗

### 根佈局
- `src/app/layout.tsx` — `NextIntlClientProvider` 包裝

### AI 翻譯
- `src/lib/translationService.ts` — Gemini AI 翻譯服務
- `src/app/api/translate/route.ts` — 翻譯 API

## 翻譯檔結構（主要命名空間）
```json
{
  "nav": { ... },         // 導覽列文字
  "common": { ... },      // 通用文字（確認、取消、貨幣等）
  "listing": { ... },     // 刊登相關
  "filter": { ... },      // 篩選器
  "ticketType": { ... },  // 票券類型
  "profile": { ... },     // 個人中心
  "notifications": { ... }, // 通知
  "forum": { ... },       // 論壇
  "language": { ... },    // 語系切換
  "settings": { ... },    // 設定
  ...
}
```

## 使用方式
```typescript
import { useTranslations } from 'next-intl';
const t = useTranslations('listing');
// 使用: t('askingPrice') → "希望分攤"
// 帶預設值: t('someKey', { defaultValue: '預設文字' })
```

## 工作流規則
- 修改程式碼後必須觸發 `/post-mod-check` 工作流
- 該工作流會檢查所有語系翻譯檔是否同步
- 新增翻譯鍵需同時更新 4 個語系檔
